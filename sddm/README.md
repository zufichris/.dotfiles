# SDDM Theme (zufi-sddm)

Glassmorphism login theme with video backgrounds, daily rotation, and matugen-driven accent colors.

## Required packages

- `sddm` (greeter, provides `sddm-greeter-qt6` used for previews)
- `qt6-declarative` (QtQuick / Controls / Layouts)
- `qt6-multimedia-ffmpeg` (video backgrounds)
- `qt6-5compat` (Qt5Compat.GraphicalEffects for blur/masks)
- `qt6-svg` (system button icons)

Install on Arch:
```bash
sudo pacman -S sddm qt6-declarative qt6-multimedia-ffmpeg qt6-5compat qt6-svg
```

## Install

```bash
sudo ./install.sh
```

This stages the theme into `/usr/share/sddm/themes/zufi-sddm`, symlinks video wallpapers from `~/Pictures/wallpapers/videos` into `backgrounds/`, sets `Current=zufi-sddm` in `/etc/sddm.conf` (original backed up), and installs + enables the daily background rotation units from `systemd/`.

Then enable SDDM:
```bash
sudo systemctl enable sddm.service
```

Background rotation (`scripts/rotate-background.sh`) picks a background by day of year (videos first, images as fallback), rotates the avatar from `AvatarDir`, and merges matugen colors from `ThemeColorsFile` (`~/.config/sddm/theme-colors.conf`, generated by `matugen/templates/sddm-colors.conf`) into the deployed `theme.conf`. install.sh enables it automatically; to (re)enable by hand:
```bash
sudo systemctl enable --now sddm-zufi-rotate-background.timer
```

## Structure

- `src/Main.qml` — root pane: background, clock, avatar, login form, system buttons
- `src/components/` — `buttons/` (login, session picker, power), `clock/` (time/date), `inputs/` (username, password), `misc/` (animated icon button)
- `src/effects/` — `Background.qml` (video / animated GIF / static image background), `BlurEffect.qml` (optional blur overlay)
- `src/layouts/` — `SystemButtonsLayout.qml` (sleep / restart / shutdown row)
- `src/ui/` — `UiTokens` singleton (spacing, radius, motion durations, easing)
- `theme.conf` — fonts, formats, background, colors; color keys are a seed that rotate-background.sh overwrites with matugen output

## Preview

```bash
./preview.sh
```

Links the video wallpaper library, runs a rotation, then launches `sddm-greeter-qt6 --test-mode` (auto-selects Wayland or X11 Qt platform).
