# Waybar

Status bar: frosted-glass pills over Hyprland's blur layer, split into per-module `modules/*.jsonc` includes and per-concern `tokens/*.css` stylesheets.

Layout is a port of the "[TOP] 0-Ja-0" layout from [JaKooLit's Hyprland-Dots](https://github.com/JaKooLit/Hyprland-Dots) (originally authored by [Muhammad Haikal Hakim](https://github.com/haikal-hakim/athena)), with the script calls rewritten for this repo (wpctl/brightnessctl, local hypr scripts, eww/swaync/wlogout integration).

## Required packages

- `waybar`
- `eww` (clock click opens the dashboard)
- `swaync` (bell module via `swaync-client`)
- `wlogout` (power button)
- `network-manager-applet` + NetworkManager (`nmcli`)
- `blueman` (Bluetooth manager)
- `ttf-jetbrains-mono-nerd` (glyphs)

Install on Arch:
```bash
sudo pacman -S waybar eww swaync wlogout network-manager-applet blueman ttf-jetbrains-mono-nerd
```

## Modules

| Module | Interaction | Action |
| --- | --- | --- |
| Distro drawer | Hover, then click | App launchers: terminal, editor, obsidian, office, files, spotify, browser |
| Workspaces | Left click | Focus workspace (window icons per app, animated active pill) |
| Network | Left / right click | Start / kill `nm-applet` tray icon |
| Network | Scroll up / down | Wi-Fi on / off |
| Bluetooth | Left click | Open `blueman-manager` |
| Bluetooth | Right click | `rfkill toggle bluetooth` |
| Battery | Left click | Toggle time-remaining readout |
| Clock | Left click | Toggle the eww `dashboard` window |
| Clock | Right click | Switch between time and date |
| Bell (tray drawer) | Left click | Open/close swaync panel |
| Bell (tray drawer) | Right click | Toggle Do Not Disturb |
| Power | Left click | Launch `wlogout` |

`F9` toggles the bar itself (`SIGUSR1`, bound in `hypr/hyprland/programs.lua`).

Spare modules (audio slider, storage, CPU/temp, power-profiles, idle inhibitor) are defined in `modules/` and styled, but not currently placed in `config.jsonc`.

`tokens/colors.css` is generated by matugen from `matugen/templates/waybar-colors.css` — edit the template, not the snapshot.
