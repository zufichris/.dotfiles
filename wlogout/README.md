# Wlogout

Power/logout menu, glass-styled to match the rest of the desktop.

## Required packages

- `wlogout`

Install on Arch:
```bash
sudo pacman -S wlogout
```

## Usage

Launched from the power button at the right end of the Waybar. There is no direct keybind — `SUPER + SHIFT + P` opens the rofi power menu (`hypr/scripts/power-menu.sh`), which offers the same actions.

Inside the menu: `l` lock, `e` logout, `h` hibernate, `s` sleep, `r` restart, `p` power off. Lock and Sleep go through `hypr/scripts/lock.sh`.

## Styling

`colors.css` is generated by matugen from `matugen/templates/wlogout-colors.css` — edit the template, not the snapshot. Button icons fall back to `/usr/share/wlogout/icons/` when no local `icons/` dir exists.
