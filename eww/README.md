# Eww

Glass dashboard overlay: a single `dashboard` window (top-center, 94% wide) laid out as a three-column card grid.

- **Column 1** — greeting/uptime, clock, quick settings (Wi-Fi, Bluetooth, DND, caffeine, notification panel; volume and brightness sliders), calendar
- **Column 2** — pomodoro ring (25/5 min, override with `POMO_FOCUS`/`POMO_BREAK`), system card (CPU, memory, swap, disk, temp, pending updates)
- **Column 3** — weather (wttr.in, 30-min cache), now-playing with album art and seek bar, notification count/clear

## Required packages

- `eww`
- `jq` (every JSON poll)
- `playerctl` (music card, media keys)
- `curl` (weather, album-art download)
- `brightnessctl`, `wireplumber` (`wpctl`) — sliders
- `networkmanager` (`nmcli`), `bluez-utils` (`bluetoothctl`), `swaync` — quick settings
- `imagemagick` (album-art placeholder), `pacman-contrib` (`checkupdates`), `hypridle` (caffeine toggle), `libnotify` (pomodoro alerts)

Install on Arch:
```bash
sudo pacman -S eww jq playerctl curl brightnessctl wireplumber networkmanager bluez-utils imagemagick pacman-contrib hypridle libnotify
```

## Usage

Toggle with the Waybar clock or `SUPER + D` (`eww open --toggle dashboard`); `Escape` closes it via a layer-scoped bind in `hypr/hyprland/keybinds.lua`. The eww daemon autostarts from `hypr/hyprland/programs.lua`.

## Layout

`eww.yuck` defines the widgets and the polls; each poll shells out to a `scripts/*.sh` helper that prints plain values or compact JSON. `eww.scss` holds the styling; `_colors.scss` is generated by matugen from `matugen/templates/eww-colors.scss` — edit the template, not the snapshot.
